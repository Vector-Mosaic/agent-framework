# Purpose and intent discovery

The [Agent Framework](../instructions/framework/README.md) owns this repository's
general purpose and complete concepts: capable, autonomous, precise and
purpose-faithful agent work. The [repository README](../../README.md) explains the
public package and intended adoption; the [documentation index](../INDEX.md)
routes implementation and operating knowledge. Accepted intent does not prove
that a capability exists or has been qualified.

An adopting project should route its own company, product, system, research and
enabling purposes by subject and practical job. These do not form a universal
inheritance ladder. Use the relevant full owner; an aspiration, charter label or
index entry neither grants work nor proves implementation. Known owners can be
read directly without loading the whole portfolio.

Keep distinct documents' jobs clear: enduring purpose, target architecture,
current behavior, exploration, evaluation and execution are different claims.
A purpose document does not supersede system Vocabulary, Contracts or observed
state. Useful broad enabling aims such as legibility and maintainability inform
work without replacing concrete conventions or system ownership.

No private company portfolio, research program, personal account, host inventory
or standing permission is imported by adopting this package. Record those details
only in the adopting user's appropriate authorized configuration and owners.
Historical plans stay historical; an old route does not become active merely
because a newer mechanism is unavailable.
