# A repair that quietly became a redesign

A user asks to restore a broken export button. The fault is a stale route. While
diagnosing it, the agent notices that the entire navigation could be redesigned.
The user says the redesign is an interesting idea but has not asked to implement
it. The export repair is straightforward and can be checked with one representative
download and a route test.

What should the agent complete now, and what should happen to the redesign idea?
Explain how your answer preserves the requested outcome without losing a useful
observation.
